# 规则裁定记录

本引擎按《冷战热斗》20 周年版基础规则实现（= Deluxe + #104–110 默认加入 + 回合末持有计分卡判负）。下面是规则书没写清、或需要在几种读法里选一种的地方。主要参考：规则书（docs/ref）、GMT FAQ、DeepStruggle 引擎的审计结论（docs/ref/deepstruggle/engine-rulings.md，该引擎用 274 局真人对局回放验证过）。

## 回合流程

| 问题 | 裁定 | 依据 |
|---|---|---|
| 发牌顺序 | 从苏联开始一张一张交替发，手牌已满的一方跳过 | DeepStruggle §14：第 3 回合牌库必然抽空，顺序影响双方拿到的牌 |
| 时期牌加入时是否重洗弃牌堆 | 不重洗，只把新时期牌和当前牌库一起洗 | 规则 4.4；DeepStruggle §10 |
| 事件中途抽空牌库（Ask Not、Our Man in Tehran） | 当场把弃牌堆洗成新牌库继续抽；Tehran 已抽出的牌不进新牌库，Ask Not 刚弃的牌会进 | DeepStruggle §13 |
| 手里只剩中国牌 | 可以跳过本行动轮 | 规则 9.8；DeepStruggle §5 |
| 第 8 个行动轮（空间站、北海油田） | 可以放弃 | DeepStruggle §5 |
| 双方回合末都持有计分卡 | 平局 | 规则未写，极少出现 |
| 回合末军事行动检查让一方到 20 VP | 直接获胜，不再检查该方是否持有计分卡 | 简化处理（规则 10.3.1 有“先亮手牌”的细节，未实现） |
| 登月特权弃牌 | 不能弃计分卡 | DeepStruggle §17：计分卡永远不能被保留 |

## 头条

| 问题 | 裁定 | 依据 |
|---|---|---|
| 结算顺序 | 印刷行动点高者先，计分卡算 0，相同美国先 | 规则 4.5 C |
| 头条打出对手的牌 | 对手执行事件，打出者是行动方（DEFCON 降到 1 时打出者输） | 规则 8.1.3 |
| 联合国干预 | 不能作为头条，也不能在头条阶段经其他途径（星球大战等）作为事件 | 卡面文字 |
| 叛逃者 | 无论通过什么途径进入头条阶段，都会取消尚未结算的苏联头条；行动轮里只在苏联打出时让美国 +1 VP，作为事件没有效果，因此不提供“事件”选项 | 卡面文字；DeepStruggle §14 |
| 头条阶段 DEFCON 降到 2 | 不触发北美防空司令部（只看行动轮） | DeepStruggle（Playdek 日志，ts-replayer 第 219 局） |

## 行动点与修正

| 问题 | 裁定 | 依据 |
|---|---|---|
| 事件给的行动点是否吃修正（遏制、勃列日涅夫、红色恐慌） | 吃 | 规则 7.4.3 与 7.4.2 例 3（FAQ 的相反说法被规则书推翻） |
| 中国牌 / 越南起义的地区加成 | 按“地区阶梯”：只要有 1 点用在亚洲以外就失去中国牌加成，用在东南亚以外就失去越南加成；每放一点都按剩余预算校验 | DeepStruggle §20 |
| 放影响力的邻接快照 | 行动轮开始（对手事件先发动时取发动前）有己方影响力、且现在仍有的国家，及其邻国 | 规则 6.1；DeepStruggle §18 |
| 放影响力必须花完行动点 | 是，除非没有能负担的目标；调整阵营可以提前停止 | DeepStruggle §6.4 |
| “may”（可以）使用行动点的事件 | 可以放弃：奥运会抵制、中情局成立、联合国干预、孤胆枪手、出售谷物（还回时）、KAL-007、公开性、军政府、推倒这堵墙、奥尔特加。反弹道导弹条约是“then conduct”，必须使用 | 卡面文字 |
| 免费政变（军政府、推倒这堵墙、奥尔特加） | 不计军事行动，无视 DEFCON 地区限制，战场国照降 DEFCON；推倒这堵墙的免费调整同样无视 DEFCON；核潜艇对免费政变无效 | 规则 6.3.5、8.2.2；DeepStruggle ops.cpp |
| 切·格瓦拉的政变 | 视为普通政变：计入军事行动、吃行动点修正 | DeepStruggle（Playdek 行为） |
| 调整阵营的超级大国加成 | 只加一次（“本国与目标相邻 +1”），不再把超级大国当作相邻受控国重复计算 | 规则书 6.2 朝鲜例子 |

## 卡牌

| 卡 | 裁定 | 依据 |
|---|---|---|

| #35 台湾决议 | 美控台湾时在亚洲计分（含终局计分）视为战场国；首脑峰会、厨房辩论不受影响 | 卡面；DeepStruggle scoring.cpp |
| #36 局部战争 | 目标是任意稳定度 ≤2 的国家，不需要有敌方影响力；北约保护的美控欧洲国家不能选；防守方的超级大国算一个相邻敌控国 | FAQ（推翻了早期裁定） |
| #45 首脑峰会 | 支配/控制的区域按原始局面算，不受穿梭外交、台湾决议影响；胜者降 DEFCON 到 1 时，行动方（打出者）输 | FAQ #73；规则 8.1.3 |
| #48 厨房辩论 / #108 我们的人在德黑兰 / #105 美英特殊关系 | 局面条件不满足时“没有效果”，带星卡进弃牌堆而不移出 | DeepStruggle §11 |
| #49 导弹嫉妒 | 计分卡不能被换走；对手只有计分卡时事件没有效果，导弹嫉妒正常进弃牌堆。换走的牌是己方或中立事件就立即发动，是对手事件则只用行动点 | DeepStruggle missile_envy_may_take |
| #50 我们将埋葬你们 | 在美国的下一个行动轮结算，不管这一轮怎么过（打牌、陷阱弃牌、跳过、空手） | DeepStruggle §15 |
| #73 穿梭外交 | 只在下一次中东或亚洲计分卡生效（东南亚计分不算），苏联有战场国时才扣，扣战场国的同时扣一个国家；用过即弃。终局计分不生效 | DeepStruggle §13、scoring.cpp |
| #80 一小步 / #100 战争游戏 | 条件（落后 / DEFCON 2）视为事件前提：不满足时不能作为事件打出 | 与 DeepStruggle 的 OWN_EVENT_GATED 规则位一致 |
| #104 剑桥五杰 | 东南亚计分卡指名的区域是东南亚 | 卡面 |
| #106 北美防空司令部 | DEFCON 在本行动轮内“移动到”2 才触发；CMC 或奇爱博士在 DEFCON 已是 2 时“设为 2”不算 | 卡面；DeepStruggle §12 |
